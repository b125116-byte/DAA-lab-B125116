 Question : To implement QuickSort on N random elements stored in a file.
 
  Steps:
    1. Generate N random numbers and write them to "input.txt"
    2. Read the numbers back from the file into an array
    3. QuickSort the array
    4. Write the sorted result to "sorted_output.txt"
 
 Time Complexity:
    Average case : O(N log N)
    Worst case    : O(N^2)  (e.g. already sorted input with poor pivot choice)
