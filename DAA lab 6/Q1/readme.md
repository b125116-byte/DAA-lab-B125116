
   1D array operations and their worst-case complexities
   ============================================================
   (i)   max                    -> O(n)
   (ii)  1st & 2nd largest      -> O(n)
   (iii) mean                   -> O(n)
   (iv)  median                 -> O(n log n)  (sort based)
   (v)   standard deviation     -> O(n)
   (vi)  mode                   -> O(n log n)  (sort based, worst-case safe;
                                    O(n) average with hashing)
   (vii) remove duplicates      -> O(n log n)  (sort based)
   (viii)reverse                -> O(n)
   (ix)  partition wrt pivot    -> O(n)  (single pass, Lomuto style)
